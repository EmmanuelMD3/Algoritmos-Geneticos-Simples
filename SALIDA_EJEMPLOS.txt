[1] Ruleta proporcional (pag. 1)
A=10 B=20 C=30 D=40 -> [0.1, 0.2, 0.3, 0.4]
Con r=0.52 se elige C (acumuladas: 0.10, 0.30, 0.60, 1.00).

[2] Ranking lineal (pag. 2)
D, C, B, A -> [0.4, 0.3, 0.2, 0.1]
Nota: el PDF propone 0.40,0.32,0.23,0.15; suman 1.10.
Se implementa la formula normalizada habitual (amin=2-amax).

[3] Ranking no lineal (pag. 3)
D, C, B, A -> [0.5333, 0.2667, 0.1333, 0.0667]

[4] Torneo binario (pag. 4)
Torneo A(10) vs C(30) -> C; B(20) vs D(40) -> D
El motor tambien sortea competidores al azar y admite k variable.

[5] Muestreo estocastico universal (pag. 5)
Cuatro punteros espaciados 1/4 -> ['B', 'C', 'D', 'D']

[6] Sustitucion steady-state (pag. 6)
A10,B20,C30,D40 + E25,F35 -> ['D', 'C', 'E', 'F']

[7] Factor de crowding (pag. 7)
N=1011; distancias Hamming con A,B,C: [1, 2, 3] -> reemplaza A

[8] Cruce uniforme (pag. 8)
Mascara=101010 -> H1= 100111 H2= 011000

[9] Cruce aritmetico (pag. 9)
P1=(2,8), P2=(6,4), a=0.25 -> ([5.0, 5.0], [3.0, 7.0])

[10] Cruce plano (pag. 10)
P1=(2,8), P2=(6,4) -> gen1 en [2,6], gen2 en [4,8]
Un hijo valido mostrado en clase: (3.1,7.2)

[11] Cruce BLX-alfa (pag. 11)
p1=2, p2=6, alfa=0.5 -> I=4, intervalo [0,8], p.ej. h=7.1

[12] Cruce PMX (pag. 12)
P1= [1, 2, 3, 4, 5, 6, 7, 8] P2= [3, 7, 5, 1, 6, 8, 2, 4]
Cortes [3..5] -> H1= [6, 7, 3, 4, 5, 8, 2, 1] H2= [4, 2, 5, 1, 6, 3, 7, 8]
Correccion: la diapositiva repite el 5; el hijo valido inicia con 6.

[13] OX (pag. 16, listado sin desarrollo)
Ejemplo adicional con los padres anteriores -> ([1, 6, 3, 4, 5, 8, 2, 7], [3, 4, 5, 1, 6, 7, 8, 2])

[14] CX (pag. 16, listado sin desarrollo)
Ejemplo adicional con los padres anteriores -> ([1, 7, 3, 4, 5, 6, 2, 8], [3, 2, 5, 1, 6, 8, 7, 4])

[15] Mutacion uniforme (pag. 13)
(2.5,7.0,1.2), mutar gen 2 a 3.4 -> (2.5,3.4,1.2)

[16] Mutacion no uniforme (pag. 14)
x=4; t=0 -> x'=7.000; t=90 -> x'=4.402

[17] Mutacion por intercambio (pag. 15)
Intercambiar posiciones 2 y 5 -> [1, 5, 3, 4, 2, 6]

Operador extra: inversion de bit para completar un AG con binarios.
